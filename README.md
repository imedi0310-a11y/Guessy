# Guessy

Guess the card on your head — a yes/no guessing game in 5 languages (العربية, English, Français, Español, Português).

## Version 0.1
- Play vs AI (3 levels), 8 categories, 293 cards
- Daily challenge (same card for everyone)
- Lifelines: hint, 50/50, extra turn · 45-second turns
- Levels (XP), wins, daily streak

## Build
Every push to `main` builds an APK on GitHub Actions and publishes it under **Releases**.
Android platform files are generated in CI with `flutter create`.
